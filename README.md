# ResumeKit India

A no-cost static MVP for a student/fresher resume builder. Open `index.html` in a browser to use it.

## Publish for free

1. Create a GitHub repository and upload these files.
2. In repository **Settings → Pages**, deploy from the `main` branch.
3. Use the resulting `github.io` link first; add a custom domain later.
4. After publishing, create a Google Search Console property, submit `sitemap.xml` (to be added when the final domain is known), and request indexing of the homepage.

## First content promotion ideas

- "Make a fresher resume from your phone in 5 minutes"
- "Three projects you can add to a BCA resume"
- "ATS-friendly resume format for Indian students"

Do not share a paid download flow until users confirm they find the free tool useful.
